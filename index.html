Your meeting workspace

Use New meeting to create a meeting, then add topics to the agenda. Each topic keeps its own preparation, notes, decisions, motions, and action items. Reorder with the drag handle or arrow buttons.

Host on dudgeon.io: upload index.html and the assets folder together. The repository’s CNAME points to minutes.dudgeon.io . No build step is required. Account storage uses Supabase; see README for initial setup. Bootstrap CSS loads from jsDelivr.

Storage: without login, data is saved in this browser. With login, meetings and templates are saved privately to your account. Wait for “Saved to your account” before closing. Use History to find past notes and Templates to start recurring meetings. Import adds meetings without replacing existing ones.

Review minutes includes proceedings and action items; preparation notes are excluded. Use Print / PDF to save a formatted copy.
