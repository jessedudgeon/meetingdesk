Your meeting workspace

Use New meeting to create a meeting, then add topics to the agenda. Each topic keeps its own preparation, notes, decisions, motions, and action items. Reorder with the drag handle or arrow buttons.

Host on dudgeon.io: upload index.html and the assets folder together. The repository’s CNAME points to minutes.dudgeon.io . No build or server database is required. Bootstrap CSS loads from jsDelivr.

Storage: data is saved in this browser on this website. It does not sync across browsers or users. Clearing site data removes saved meetings. Export backups regularly. Import adds meetings without replacing existing ones.

Review minutes includes proceedings and action items; preparation notes are excluded. Use Print / PDF to save a formatted copy.
